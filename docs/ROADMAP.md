# Roadmap — Probably-TAU

**План, не факт выполнения.** Оценки обсуждаются после реализации вертикального среза.

## Фаза 0 — определение дизайна
- Утвердить названия, художественный стиль, объём первого дня и критерии успеха.
- Зафиксировать публичные контракты Core, валютные единицы, правила времени, ID и RNG.
- Нарисовать дешёвые wireframes кабинета и заявок.
- Составить 10–12 событий с осмысленными последствиями.

**Выход:** целостная спецификация vertical slice.

## Фаза 1 — технический фундамент
- Реальный Unity 6 проект + структура папок и .gitignore.
- Core GameState, CommandProcessor, игровые часы, Economy/Ledger, EventQueue.
- EditMode unit-тесты детерминизма, экономических инвариантов.

**Выход:** команда «Следующий день» детерминированно обновляет состояние и экономику.

## Фаза 2 — интерактивный кабинет
- Сцена кабинета; посетитель, очередь, текст и портрет-заглушка.
- Карточка документа + осмотр + минимум три результата решения.
- Вечерний отчёт и переход к следующему дню.

**Выход:** 15–30 минут вертикального среза.

## Фаза 3 — последствия и расширение
- Отложенные события, переговоры, 4 группы репутации.
- Прогресс проектов, базовые связи между системами.
- Сохранения v1, Save→Load regression tests.

**Выход:** связанная игра без поломок в повторных прохождениях.

## Фаза 4 — учебный MVP
- 30 дней, 8–12 архетипов, 30–50 событий, 8 типов документов.
- 10–15 проектов, 3 сложности, 3 исхода.
- Оригинальные ассеты, звук, обучение, доступность, баланс, Windows build.

**Выход:** законченный учебный MVP.

## Не начинать до готовности vertical slice
Мультиплеер, сетевой бекенд, open-world campus, 3D, много платформ, монетизация, реалистичная симуляция 1000 студентов.
