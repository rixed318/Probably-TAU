# Журнал решений (ADR-lite)

**Последнее обновление:** 14.11.2026.

## Принято / зафиксировано для предпроекта
- D-001. Оригинальная учебная игра про ТАУ, роль игрока — вымышленный президент академии.
- D-002. Unity + C#, одиночная 2D-игра, первоначально Windows.
- D-003. Probably Stolen — референс системной увлекательности, **не** цель прямого клонирования.
- D-004. Первый игровой цикл: посетители, документы, проверка, решения, бюджет/отношения, конец дня и последствия.
- D-005. GitHub `rixed318/Probably-TAU` — основное хранилище работы, чаты разделяются по подсистемам.
- D-006. GDD v0.1 — предварительный дизайн, не окончательная спецификация. Код проекта пока не создан.

## Технические рекомендации — требуют утверждения
- P-001. Unity 6 LTS, разделение Core/Application/Presentation/Infrastructure.
- P-002. UI Toolkit для интерфейса, ScriptableObject для definitions.
- P-003. Детализация GameState, команда/событие, versioned snapshots.
- P-004. Начальный vertical slice 15–30 минут, учебный MVP 30 игровых дней.
- P-005. Целочисленная денежная модель, seed-based воспроизводимость.

## Открытые вопросы
- O-001. Финальное название и разрешённые материалы/логотип ТАУ.
- O-002. Художественный стиль: pixel art или иной 2D.
- O-003. Тон: управленческая драма, мягкая сатира или смешанный.
- O-004. Стартовые ресурсы, правила сложности, поведение негативного бюджета.
- O-005. Как именно выглядит кабинет и удобный UI.
- O-006. Дата сдачи институтского проекта и доступное время разработки.
- O-007. Формат лицензии / публичность кода и ресурсов. Репозиторий публичный, но свободная лицензия **не выбрана**.

## Процесс
Новое решение: дата, ID, контекст, варианты, принятое решение, последствия, ссылки на PR/Issue. Не редактировать исторические решения задним числом без пометки о замене.
