# Probably-TAU — ТАУ: Президент Академии

**Статус:** pre-production / концепция v0.1 (14.11.2026).  
**Тип:** оригинальная одиночная 2D-игра о руководстве Тольяттинской академией управления.  
**Технологии:** Unity 6 (LTS), C#, Windows PC.  
**Игровая модель:** управленческий симулятор с посетителями, документами, переговорами, экономикой, долгосрочными последствиями решений и событиями.

> Название репозитория Probably-TAU — рабочее. Probably Stolen используется только как референс по системному дизайну и вовлечению; мы не копируем её код, ассеты, персонажей, визуальный стиль или сюжет. Официальные данные ТАУ и игровые вымышленные допущения должны быть разделены.

## Ключевая идея

Игрок — **вымышленный новый президент ТАУ** (полномочия в игре художественно расширены). Он рассматривает заявки, общается со студентами, преподавателями и партнёрами, распределяет бюджет, развивает академию и реагирует на последствия прежних решений. Игрок балансирует между деньгами, качеством обучения, интересами студентов, сотрудников, работодателей и репутацией.

**Один игровой цикл:** начало дня → посетители/документы → проверка информации → решение/переговоры → изменение ресурсов и отношений → конец дня → расходы, сроки, отложенные последствия → следующий день.

## Разработка

Пока здесь **только документация и задачи**. Играбельной Unity-сборки ещё нет. После реализации игры Unity-проект расположится в `unity/` либо будет перенесён в корень решением ADR — не создавать фиктивную структуру Unity без настоящего проекта.

## Первые действия

1. Прочитать `AGENTS.md`, `docs/GDD.md` и `docs/DECISIONS.md`.
2. Выбрать свою систему из `docs/CHAT_WORKFLOW.md`.
3. Создать ветку `feature/<название>` и реализовать ограниченную задачу.
4. Добавить/обновить тесты и документацию, сделать Pull Request.
5. После интеграции зафиксировать изменения в `docs/DECISIONS.md` и краткий handoff.
